# System Prompt

You are given text fragments extracted by OCR from a Malay newspaper page written in Jawi (Arabic script).

Each fragment is a JSON object with the following fields:

- id: fragment identifier
- text: OCR text content
- type: block type (e.g., "text", "header")
- hpos: horizontal position (pixels from left)
- vpos: vertical position (pixels from top)
- width: block width in pixels
- height: block height in pixels
- predicted_class: (Optional) the class predicted for this fragment in a previous step (e.g., "article", "advertisement", "obituary", "miscellaneous")

Your task: reconstruct these fragments into complete items, but ONLY for articles and miscellaneous items.

Follow this process for each group of fragments:

1. Group fragments that belong to the same item together. Some items may consist of a single fragment.
2. Determine the type of each item:
   - "article": news stories, reports, editorials, and similar journalistic content
   - "advertisement": commercial ads, product listings, promotional content
   - "obituary": death notices, memorial announcements
   - "miscellaneous": letters, captions, short notices, and other content that is not an article, advertisement, or obituary
3. OMIT any items classified as "obituary" or "advertisement" -- do not include them in the output.
4. Only include items classified as "article" or "miscellaneous".

For each item you include, provide:

1. fragment_ids: list of constituent fragment IDs (in reading order)
2. title: a short title or topic description
3. class: one of "article", "miscellaneous"

Return ONLY a JSON array of articles and miscellaneous items. Do not include obituaries or advertisements. No other text, no explanation. Example:
[
{"fragment_ids": ["r_1", "r_2"], "title": "Union meeting report", "class": "article"},
{"fragment_ids": ["r_5"], "title": "Editor's note", "class": "miscellaneous"}
]

# User Prompt Template

Fragments from a Malay newspaper page (Jawi / Arabic script):

{fragments}

First identify what type of item each group of fragments represents. If a fragment contains a `predicted_class`, use it to help group fragments together; fragments with different predicted classes rarely belong to the same item. Omit obituaries and advertisements. Reconstruct only articles and miscellaneous items. Return ONLY a JSON array.
